# Tech-gallery

A minimal React + TypeScript + Vite portfolio section featuring the original
ReactBits `CircularCarousel` populated with technology icons from Skill Icons.

## Run locally

```bash
npm install
npm run dev
```

To create a production build:

```bash
npm run build
npm run preview
```

The icons are loaded from `https://skillicons.dev/icons`. An internet connection
is required for those remote assets to render.
